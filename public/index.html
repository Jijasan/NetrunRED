05 КРАТКИЕ ПРАВИЛА

Ход: одно Мясное Действие или все доступные Сетевые Действия. Перемещаться можно всегда.

Сетевые Действия: Интерфейс 1–3: 1; 4–6: 2; 7–9: 3; 10: 4.

Проверки: Интерфейс + 1d10 против СЛ. Результат должен превысить СЛ.

Критический d10: при 10 бросьте ещё раз и прибавьте результат; при 1 бросьте ещё раз и вычтите результат.

Перемещение: можно пройти любое число открытых связанных узлов; Пароли и другие препятствия блокируют путь.

Чёрный ЛЁД: при встрече Интерфейс + Скорость + 1d10 против Скорости ЛЬДА + 1d10. При победе ЛЁД немедленно применяет Эффект.

Ускользнуть: один раз за Ход, Интерфейс + 1d10 против Восприятия ЛЬДА + 1d10.

Разряд: Интерфейс + 1d10 против защиты цели + 1d10; при попадании 1d6 урона.

Краткая памятка по Cyberpunk RED v1.25e, стр. 197–210. Полные эффекты и особые случаи смотрите в книге правил.
