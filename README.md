# НЕТРАН // Общая Архитектура

Локальный стол для Нетраннинга в Cyberpunk RED с двумя ролями. Мастер видит полную Архитектуру СЕТИ и управляет открытием этажей; Нетраннер видит только обнаруженные этажи. Оба экрана синхронизируются через локальный сервер.

## Запуск

Требуется Node.js 18 или новее. Устанавливать пакеты не нужно.

```powershell
npm start
```

Откройте:

- Мастер: `http://localhost:4173/?role=gm`
- Нетраннер: `http://localhost:4173/?role=runner`

Для второго устройства в той же локальной сети замените `localhost` на локальный IP-адрес компьютера, где запущен сервер. Сессия автоматически сохраняется в `game-state.json`.

## Возможности

- Общие Ходы, подключение, Здоровье мозга, Сетевые Действия, Программы, броски и журнал событий
- Количество Сетевых Действий в зависимости от Ранга Интерфейса
- Скрытые и открытые этажи Архитектуры и позиция Нетраннера; скрытые этажи не раскрывают даже общее количество уровней
- Русские термины из книги: Пароль, Файл, Управляющий Узел и Чёрный ЛЁД
- Характеристики Аспида, Великана и Адской Гончей
- Управление Архитектурой для Мастера и безопасный экран Нетраннера
- Краткая памятка по главе «Нетраннинг» из *Cyberpunk RED* v1.25e, стр. 195–210

Это неофициальный игровой инструмент. Для полных Эффектов Программ, особых случаев боя и решений Мастера необходима книга правил.
